# Ana Karla | TechLab

Portfólio de suporte de TI e desenvolvimento de software, construído com React + Vite.

## Executar

```bash
npm install
npm run dev
```

## Publicar

```bash
npm run build
```

## Conteúdo

- Apresentação profissional e trajetória
- Simulador didático de diagnóstico de TI
- Projetos e contatos
- Terminal interativo

**Nota:** o simulador é educacional e não substitui um diagnóstico técnico presencial. Os projetos indicados como estudos não são experiências profissionais comprovadas.
